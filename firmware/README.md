# Firmware: pendiente de Fase 2

Destino previsto: ESP32-S3, C++ con Arduino Framework y PlatformIO; comunicación inicial por USB serial. No se distribuye firmware ni se asignan pines hasta identificar la placa y los sensores reales.

La Fase 1 permite registrar el dispositivo como configuración, sin afirmar una conexión física. La ingesta, calibración, heartbeat y reconexión se implementarán y probarán en Fase 2. No hay control de actuadores.
