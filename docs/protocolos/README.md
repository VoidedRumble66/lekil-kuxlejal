# Protocolos pendientes de instrumentación

La Fase 1 no abre puertos ni envía comandos. El protocolo USB serial se definirá en la segunda fase después de identificar placa, sensores y unidades reales. Debe versionar el formato, identificar dispositivo/sensor/zona, transmitir timestamp y calidad, limitar tamaño de mensajes y documentar errores, reconexión y calibración. No se asignan pines por anticipación.

Las reglas de evidencia y emergencia provienen de [REQUISITOS.md](../REQUISITOS.md) y del expediente, pp. 39 y 58-60. Antes de habilitar un actuador se requerirán límites, autorización, confirmación, cancelación manual y prueba física.
